# Falcon and sentry

Sentry default: current context = per thread

Falcon reality: current request = per fiber

Our fix: current Sentry context = per fiber

```ruby
module SentryFalconFiberLocalHub
  FIBER_LOCAL_HUB_KEY = :__sentry_current_hub__

  def get_current_hub
    return unless initialized?

    Fiber[FIBER_LOCAL_HUB_KEY] ||= get_main_hub.clone
  end

  def clone_hub_to_current_thread
    return unless initialized?

    Fiber[FIBER_LOCAL_HUB_KEY] = get_main_hub.clone
  end

  def set_current_hub(hub)
    Fiber[FIBER_LOCAL_HUB_KEY] = hub
  end
end
Sentry.singleton_class.prepend(SentryFalconFiberLocalHub)
```
