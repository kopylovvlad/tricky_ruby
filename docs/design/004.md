# Явные контракты важнее магии

Архитектурно зрелый код любит предсказуемые входы и выходы. Не "метод как-нибудь поймёт", а: что принимает; что возвращает; какие инварианты требует.

## Плохо

```ruby
def generate_report(data)
  # data может быть чем угодно
end
```

## Лучше

```ruby
ReportInput = Data.define(:from, :to, :users)

class GenerateReport
  def call(input)
    raise ArgumentError, "from required" unless input.from
    raise ArgumentError, "to required" unless input.to

    # ...
  end
end
```

Архитектура любит формальные входы. Лучше передать один объект-контракт, чем 7 неочевидных аргументов
