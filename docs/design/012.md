# Идемпотентность

Повторный запуск не должен ломать мир

## Плохо

Повторил скрипт — выдал бонус дважды

```ruby
users.each do |user|
  Bonus.create!(user_id: user.id, points: 100)
end
```

## Лучше

```ruby
users.each do |user|
  Bonus.find_or_create_by!(user_id: user.id, reason: "spring_campaign") do |bonus|
    bonus.points = 100
  end
end
```

Хороший batch job должен быть безопасен при повторе. Архитектура скрипта включает сценарии перезапуска. Важны unique keys, checkpoints, markers
