# Конфигурация отдельно, поведение отдельно

## Плохо

```ruby
class Backup
  def call
    system("tar -czf backup.tar.gz /var/data")
    Net::SFTP.start("prod.example.com", "root", password: "123456") do |sftp|
      sftp.upload!("backup.tar.gz", "/backups/backup.tar.gz")
    end
  end
end
```

## Лучше

```ruby
BackupConfig = Data.define(:source_dir, :archive_path, :host, :user, :password)

class Backup
  def initialize(config:, archiver:, uploader:)
    @config = config
    @archiver = archiver
    @uploader = uploader
  end

  def call
    @archiver.archive(@config.source_dir, @config.archive_path)
    @uploader.upload(@config.archive_path)
  end
end
```

Конфиг — это данные. Логика — это поведение. Нельзя смешивать policy и mechanism
