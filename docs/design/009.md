# Композиция чаще лучше наследования

Этим очень легко злоупотреблять

## Плохо

Наследование тут нужно только ради одного метода.

```ruby
class BaseImporter
  def log(message)
    puts message
  end
end

class CsvImporter < BaseImporter
  def import(path)
    log("importing #{path}")
  end
end
```

## Лучше

```ruby
class Logger
  def info(message)
    puts message
  end
end

class CsvImporter
  def initialize(logger:)
    @logger = logger
  end

  def import(path)
    @logger.info("importing #{path}")
  end
end
```

Наследование связывает сильнее, чем кажется. Композиция даёт гибкость и локальность изменений. Inheritance — для is-a, а не для "мне нужен общий helper"
