# Архитектура начинается с именования

Плохая архитектура часто маскируется общими именами: Manager, Processor, Service, Handler, Utils.

Хорошая архитектура любит точные роли: InvoiceRepository, RetryPolicy, ReportFormatter, WebhookVerifier, UserImporter.

Имя должно отражать роль в системе. Имя Service не объясняет архитектуру. Плохие имена размывают границы
