# Явное управление состоянием

Архитектурно зрелый код умеет ответить где живёт состояние, кто его меняет, когда и по каким правилам?

## Плохо

Состояние глобальное, мутируется отовсюду

```ruby
class Deploy
  @@status = {}

  def self.run(app)
    @@status[app] = :running
    # ...
    @@status[app] = :done
  end
end
```

## Лучше

```ruby
class DeployState
  def initialize
    @statuses = {}
  end

  def start(app)
    @statuses[app] = :running
  end

  def finish(app)
    @statuses[app] = :done
  end

  def status(app)
    @statuses[app]
  end
end
```

И ещё лучше — если состояние вообще можно не хранить глобально, а передавать явно. Потому, то global state почти всегда архитектурный долг. Shared mutable state опаснее длинных методов. У состояния должен быть владелец
