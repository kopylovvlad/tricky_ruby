# Явная модель данных лучше “хэшей повсюду”

Ruby провоцирует писать всё на hash. Для прототипа нормально. Для архитектуры — часто вредно.

## Плохо

```ruby
user = { name: "Ann", role: "admin", active: true }
```

Потом по всему проекту `user[:role]`, `user["role"]`

## Лучше

```ruby
User = Data.define(:name, :role, :active) do
  def admin?
    role == "admin"
  end
end
```

Архитектура любит устойчивые формы данных. Hash удобен на границе системы. Внутри лучше переходить к объектам/структурам/DTO
