# Отделение бизнес-логики от инфраструктуры

Доменная логика не должна думать про HTTP, PostgreSQL, Sidekiq, Rails, ENV и filesystem. Именно это часто отличает “скрипт” от “архитектурного кода”.

## Плохо

Здесь логика скидки смешана с ActiveRecord и системным временем.

```ruby
class DiscountCalculator
  def call(user_id)
    user = User.find(user_id)
    return 0 if user.banned?

    if Time.now.friday?
      15
    else
      5
    end
  end
end
```


## Лучше

```ruby
class DiscountCalculator
  def initialize(clock:)
    @clock = clock
  end

  def call(user)
    return 0 if user.banned?

    @clock.friday? ? 15 : 5
  end
end

class SystemClock
  def friday?
    Time.now.friday?
  end
end

user = User.find(user_id)
discount = DiscountCalculator.new(clock: SystemClock.new).call(user)
```

Доменная логика должна работать на простых объектах и абстракциях. Инфраструктура — на краях системы. Внешний мир должен подключаться, а не быть вшит в алгоритм
