# Side effects должны быть на краях

Чем глубже внутрь системы — тем меньше side effects. Чем ближе к краям — тем больше IO.

## Плохо

Метод одновременно читает, преобразует, пишет.

```ruby
def normalize_users(path)
  users = JSON.parse(File.read(path))
  normalized = users.map { |u| u.transform_keys(&:downcase) }
  File.write(path, JSON.pretty_generate(normalized))
  normalized
end
```

## Лучше

```ruby
class UserNormalizer
  def self.call(users)
    users.map { |u| u.transform_keys(&:downcase) }
  end
end

users = JSON.parse(File.read(path))
normalized = UserNormalizer.call(users)
File.write(path, JSON.pretty_generate(normalized))
```

Это про pure core, impure shell. Тестируемость рождается из отделения вычисления от действий. Side effect на краю легче заменить, логировать, ретраить, изолировать
