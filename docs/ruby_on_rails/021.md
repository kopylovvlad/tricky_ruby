# Thread safe validation

ThreadSafeValidator solves this problem by creating new validator instance for each validation run

```ruby
class ThreadSafeValidator < ActiveModel::Validator
  def validate(record)
    self.class.new(options).thread_safe_validate(record)
  end

  def thread_safe_validate(_record)
    raise Exceptions::NotImplementedInterfaceError
  end
end
```
